schematic: upgrade all 7 sheets to KiCad 10 format (20231120 -> 20260306)

ROOT CAUSE of the error JP kept seeing, finally proven: the schematic was
written in KiCad 8 format (version 20231120) while KiCad 10.0.7 is installed.
KiCad 10 warns that the file was created with an older version and must be
upgraded. Nothing was wrong with the design - only the file format.

Evidence: sgc_p1.kicad_pcb (written by KiCad 10 pcbnew) is version 20260206,
while every .kicad_sch was version 20231120 with generator sgc_gen. That
generator literal is hardcoded in gen_schematic.py:194.

FIX: kicad-cli sch upgrade - the sanctioned, scriptable path - applied to
all 7 sheets. 20231120 -> 20260306.

PROOF THE ELECTRICAL CONTENT IS UNCHANGED:
  before lines: 9321
  after  lines: 9321
  IDENTICAL (excluding date/generator header)
Both netlists exported from the same KiCad 10.0.7, compared by
tools/netdiff_check.py ignoring the date/generator header. 79 components,
121 nets, no annotation warning.

(mcu 110 -> 175 KB, sensors 156 -> 245 KB).
