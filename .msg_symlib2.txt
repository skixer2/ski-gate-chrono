schematic: symbol library in true KiCad 10 format (20251024)

The previous commit on this path carried the STALE file: git on the gateway held
version 20231120 with 99 old-style "(effects ...) hide" tokens and zero
"(hide yes)". The upgraded file only ever existed on JP-PC, uncommitted, so the
repo kept handing KiCad an old-format library.

sym-lib-table loads this library on project open. KiCad 10 migrated it in memory
on every load and reported "An error was found when loading the schematic that
has been automatically fixed" - which is why the dialog survived three rounds of
sheet-level fixes.

This commit replaces it with the genuinely upgraded file:
  version      20251024
  (hide yes)   99
  (show_name)  155
  old hide     0

Verified non-destructive: 31 symbols and 272 pins, identical before and after.
gen_symbols.py now runs "kicad-cli sym upgrade" after writing, so regeneration
cannot revert the library to KiCad 8 format again.
